Objects & Arrays:
Reference vs Copy

Why changing one variable mysteriously mutates another? Master memory pointers and eliminate mutation bugs forever.

🧊 Primitives

Values like Strings, Numbers, and Booleans are copied by value.

let a = 5; let b = a; b++;
// a is 5, b is 6

🔗 References

Objects and Arrays point to a memory location. They aren't copied automatically!

let a = [1]; let b = a; b.push(2);
// a AND b are [1, 2]

✨ Deep Copies

To safely clone nested data without linked references, use deep copies.

const clone = structuredClone(obj);
